# Football Manager

Open index.html in je browser. De volledige game draait met vanilla HTML, CSS en JavaScript. Je carrière wordt automatisch lokaal bewaard in je browser.

## Inbegrepen
- Dashboard en competitiestanden (30 clubs, 3 reeksen)
- Spelerskern, basis/reserve, spelersdetails en transfers
- Tactieken en formaties
- Training en trainingslog
- Transfermarkt, clubkas en stadionuitbreiding
- Live wedstrijdsimulator en seizoensafsluiting
